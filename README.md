## Components

- **ESP32** — Microcontroller
- **Webcam** — Visual perception
- **HC-SR04** — Ultrasonic distance measurement
- **DC Gear Motors** — Wheel movement
- **Battery** — Power supply
- **Chassis** — Car base and component mounting
- **MuJoCo** — Robot simulation
